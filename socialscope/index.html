Privacy and data limits

This version uses the official YouTube Data API for channel information, public uploads and public comment threads. It does not expose private liked videos, saved videos, watch history, private messages, hidden follows or personal IP addresses. TikTok, Instagram and X need separate approved API access and are not active in this starter build. Public DNS records belong to websites, not account owners.
